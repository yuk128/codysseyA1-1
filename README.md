# 코디세이 미션 A1-1

## 1. 프로그램 소개
GenAI 미션을 진행하면서 쌓인 프롬프트들을 메모장, 노션, 메신저 등에 흩어놓지 않고 한곳에서 등록·검색·즐겨찾기로 관리하기 위해 만든 콘솔 기반 프롬프트 관리 프로그램입니다. Python 기초 문법(변수, 조건문, 반복문, 함수, 리스트/딕셔너리)과 Git 사용법을 함께 익히는 것을 목표로 합니다.

## 2. 개발 환경
- Python 3.10 이상
- VSCode + Python Extension
- Git / GitHub
- 외부 라이브러리 없이 기본 문법(`json` 표준 라이브러리만 사용)으로 구현

## 3. 설치 및 실행 방법
```
git clone <저장소 URL>
cd <저장소 폴더>
python main.py
```
- 실행 시 `prompts.json` 파일이 있으면 그 데이터를 불러오고, 없으면 기본 프롬프트 6개로 시작합니다.
- 기능을 하나 수행할 때마다, 그리고 종료(`q`)할 때 `prompts.json`에 자동으로 저장됩니다.

## 4. 기능 목록

**1. 프롬프트 추가**
- 제목, 내용, 카테고리를 입력받아 새 프롬프트를 등록합니다.
- 입력값이 비어있으면 다시 입력을 요청합니다.
- 카테고리를 기존 목록에 없는 이름으로 입력하면 새 카테고리로 자동 등록됩니다.
- 즐겨찾기 기본값은 `False`입니다.

**2. 목록 보기**
- 등록된 모든 프롬프트를 `번호. 제목⭐ 카테고리` 형식으로 출력합니다.

**3. 카테고리별 조회**
- 카테고리 목록을 보여주고 번호를 선택하면 해당 카테고리의 프롬프트만 출력합니다.

**4. 검색**
- 키워드를 입력받아 제목 또는 내용에 포함된 프롬프트를 검색합니다.
- 검색 결과가 없으면 안내 메시지를 출력합니다.

**5. 즐겨찾기 목록**
- 즐겨찾기로 등록된 프롬프트만 모아서 보여줍니다.

**6. 상세보기**
- 번호를 입력하면 해당 프롬프트의 제목, 카테고리, 즐겨찾기 여부, 내용 전체를 보여줍니다.
- 이 화면에서 아래 세부 기능을 이어서 선택할 수 있습니다.
  - 1) 수정: 제목/내용/카테고리를 새로 입력받아 덮어씁니다.
  - 2) 삭제: 해당 프롬프트를 목록에서 제거합니다.
  - 3) 즐겨찾기 추가/해제: 즐겨찾기 상태를 토글합니다.
  - 4) 뒤로가기: 메인 메뉴로 돌아갑니다.

**7. 내보내기**
- 전체 프롬프트를 카테고리별로 묶어 `prompts.md` 파일로 내보냅니다.

**q. 종료**
- 데이터를 저장하고 프로그램을 종료합니다.

## 5. 화면 예시
> 실행 결과 스크린샷을 이 자리에 첨부합니다. (메뉴, 추가, 목록, 검색 등)

## 6. 데이터 구조
`prompts.json`은 아래와 같은 형태로 저장됩니다.
```json
{
  "categorys": ["텍스트 생성", "이미지 생성", "자동화"],
  "prompts": [
    {
      "id": 1,
      "title": "SEO 블로그 글 작성",
      "content": "주어진 주제로 SEO에 최적화된 블로그 글을 작성해줘.",
      "category": "텍스트 생성",
      "favorite": true
    }
  ]
}
```
| 키 | 설명 |
|---|---|
| id | 프롬프트 고유 번호 (수정/삭제해도 변하지 않음) |
| title | 프롬프트 제목 |
| content | 프롬프트 전체 내용 |
| category | 소속 카테고리 |
| favorite | 즐겨찾기 여부 (true/false) |

## 7. 카테고리 안내
기본으로 등록된 카테고리는 다음과 같습니다.
- **텍스트 생성**: 글쓰기, 번역, 요약 등 텍스트 작성 관련 프롬프트
- **이미지 생성**: 이미지/썸네일 생성 관련 프롬프트
- **자동화**: 요약, 정리, 반복 작업 자동화 관련 프롬프트

고정된 목록이 아니며, 프롬프트 추가·수정 시 목록에 없는 이름을 입력하면 새 카테고리로 자동 등록됩니다.

## 8. 기본 프롬프트 데이터
`prompts.json`이 없을 때(최초 실행 시) 아래 6개가 기본 데이터로 등록됩니다.
1. SEO 블로그 글 작성 (텍스트 생성)
2. 비즈니스 영문 이메일 번역 (텍스트 생성)
3. 3D 스마트워치 썸네일 (이미지 생성)
4. 카페 인테리어 컨셉샷 (이미지 생성)
5. 뉴스 기사 3줄 요약 (자동화)
6. 주간 업무 보고서 정리 (자동화)

## 9. 파일 구조
| 파일 | 설명 |
|---|---|
| main.py | 프로그램 본체 |
| prompts.json | 프롬프트/카테고리 데이터 저장 파일 (자동 생성) |
| prompts.md | 내보내기(7번) 기능으로 생성되는 카테고리별 정리 파일 |

## 10. 보너스 기능
- **JSON 저장/불러오기**: 기능 수행마다 `prompts.json`에 자동 저장되고, 실행 시 자동으로 불러옵니다.
- **Markdown 내보내기**: 7번 메뉴에서 전체 프롬프트를 카테고리별로 묶어 `prompts.md`로 내보냅니다.
- **수정/삭제**: 상세보기(6번) 화면에서 프롬프트를 수정하거나 삭제할 수 있습니다.
- **즐겨찾기 토글**: 상세보기 화면에서 즐겨찾기를 바로 추가/해제할 수 있습니다.

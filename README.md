# 프롬포트 정리 프로그램

## 1. 프로그램 소개
GenAI 미션을 진행하면서 쌓인 프롬프트들을 메모장, 노션, 메신저 등에 흩어놓지 않고 한곳에서 등록·검색·즐겨찾기로 관리하기 위해 만든 콘솔 기반 프롬프트 관리 프로그램입니다. Python 기초 문법(변수, 조건문, 반복문, 함수, 리스트/딕셔너리)과 Git 사용법을 함께 익히는 것을 목표로 합니다.

## 2. 개발 환경
- Python 3.10 이상
- VSCode + Python Extension
- Git / GitHub
- 외부 라이브러리 없이 기본 문법(`json` 표준 라이브러리만 사용)으로 구현

- `git --version` 실행 결과
- `git config --global user.name`, `git config --global user.email` 실행 결과


> `git clone` 실행 로그(터미널 캡처)를 이 자리에 첨부합니다.

## 5. 기능 목록

**1. 프롬프트 추가**
- 제목, 내용, 카테고리를 입력받아 새 프롬프트를 등록합니다.
- 입력값이 비어있으면 다시 입력을 요청합니다.
- 카테고리를 기존 목록에 없는 이름으로 입력하면 새 카테고리로 자동 등록됩니다.
- 즐겨찾기 기본값은 `False`입니다.

**2. 목록 보기**
- 등록된 모든 프롬프트를 `번호. 제목⭐ 카테고리` 형식으로 출력합니다.

**3. 카테고리별 조회**
- 카테고리 목록을 보여주고 번호를 선택하면 해당 카테고리의 프롬프트만 출력합니다.

**4. 검색**
- 키워드를 입력받아 제목 또는 내용에 포함된 프롬프트를 검색합니다.
- 검색 결과가 없으면 안내 메시지를 출력합니다.

**5. 즐겨찾기 목록**
- 즐겨찾기로 등록된 프롬프트만 모아서 보여줍니다.

**6. 상세보기**
- 번호를 입력하면 해당 프롬프트의 제목, 카테고리, 즐겨찾기 여부, 내용 전체를 보여줍니다.
- 이 화면에서 아래 세부 기능을 이어서 선택할 수 있습니다.
  - 1) 수정: 제목/내용/카테고리를 새로 입력받아 덮어씁니다.
  - 2) 삭제: 해당 프롬프트를 목록에서 제거합니다.
  - 3) 즐겨찾기 추가/해제: 즐겨찾기 상태를 토글하고 결과 메시지를 출력합니다. (변경된 상태는 이후 목록 보기·즐겨찾기 목록에서 다시 조회하면 확인할 수 있습니다.)
  - 4) 뒤로가기: 메인 메뉴로 돌아갑니다.

**7. 내보내기**
- 전체 프롬프트를 카테고리별로 묶어 `prompts.md` 파일로 내보냅니다.

**q. 종료**
- 데이터를 저장하고 프로그램을 종료합니다.

> 메뉴 출력 화면, 프롬프트 추가, 목록, 검색 등 각 기능 실행 결과 스크린샷을 이 자리에 첨부합니다.

## 6. 데이터 구조
`prompts.json`은 아래와 같은 형태로 저장됩니다.
```json
{
  "categorys": ["텍스트 생성", "이미지 생성", "자동화"],
  "prompts": [
    {
      "id": 1,
      "title": "SEO 블로그 글 작성",
      "content": "주어진 주제로 SEO에 최적화된 블로그 글을 작성해줘.",
      "category": "텍스트 생성",
      "favorite": true
    }
  ]
}
```
| 키 | 설명 |
|---|---|
| id | 프롬프트 고유 번호 (수정/삭제해도 변하지 않음) |
| title | 프롬프트 제목 |
| content | 프롬프트 전체 내용 |
| category | 소속 카테고리 |
| favorite | 즐겨찾기 여부 (true/false) |

**리스트·딕셔너리를 함께 쓴 이유**
- `prompts`는 여러 개의 프롬프트를 순서대로 담아야 해서 리스트를 사용했습니다.
- 프롬프트 한 개는 제목/내용/카테고리/즐겨찾기/id처럼 이름이 있는 여러 값을 묶어야 해서 딕셔너리를 사용했습니다.
- 즉 "리스트 안에 딕셔너리가 여러 개 들어있는 구조"로, 여러 항목을 관리하면서도 각 항목의 세부 값에 이름으로 접근할 수 있다는 장점이 있습니다.

**id 중복 및 카테고리 충돌 처리**
- 새 프롬프트를 추가할 때 `id`는 `len(prompts) + 1`로 부여되어 항상 새 번호가 생성되며, 기존 항목과 중복되지 않습니다.
- 카테고리는 입력값이 `categorys` 목록에 이미 있으면 기존 카테고리를 그대로 재사용하고, 없을 때만 새 카테고리로 추가하므로 같은 이름의 카테고리가 중복 생성되지 않습니다.

**저장 형식으로 JSON을 선택한 이유**
- JSON은 파이썬 딕셔너리/리스트 구조를 거의 그대로 저장할 수 있어 별도 변환 작업이 적습니다.
- CSV는 표 형태라 프롬프트처럼 값 하나(내용)가 길고 줄바꿈이 들어갈 수 있는 데이터에는 적합하지 않습니다.
- SQLite 같은 DB는 여러 프로그램이 동시에 접근하거나 데이터 양이 매우 많을 때 유리하지만, 이 프로그램은 혼자 실행하는 콘솔 프로그램이라 파일 하나로 관리되는 JSON이 더 간단합니다.

## 7. 카테고리 안내
기본으로 등록된 카테고리는 다음과 같습니다.
- **텍스트 생성**: 글쓰기, 번역, 요약 등 텍스트 작성 관련 프롬프트
- **이미지 생성**: 이미지/썸네일 생성 관련 프롬프트
- **자동화**: 요약, 정리, 반복 작업 자동화 관련 프롬프트

고정된 목록이 아니며, 프롬프트 추가·수정 시 목록에 없는 이름을 입력하면 새 카테고리로 자동 등록됩니다.

## 8. 기본 프롬프트 데이터
`prompts.json`이 없을 때(최초 실행 시) 아래 6개가 기본 데이터로 등록됩니다.
1. SEO 블로그 글 작성 (텍스트 생성)
2. 비즈니스 영문 이메일 번역 (텍스트 생성)
3. 3D 스마트워치 썸네일 (이미지 생성)
4. 카페 인테리어 컨셉샷 (이미지 생성)
5. 뉴스 기사 3줄 요약 (자동화)
6. 주간 업무 보고서 정리 (자동화)

## 9. 파일 구조
| 파일 | 설명 |
|---|---|
| main.py | 프로그램 본체 |
| prompts.json | 프롬프트/카테고리 데이터 저장 파일 (자동 생성) |
| prompts.md | 내보내기(7번) 기능으로 생성되는 카테고리별 정리 파일 |

## 10. 보너스 기능
- **JSON 저장/불러오기**: 기능 수행마다 `prompts.json`에 자동 저장되고, 실행 시 자동으로 불러옵니다.
- **Markdown 내보내기**: 7번 메뉴에서 전체 프롬프트를 카테고리별로 묶어 `prompts.md`로 내보냅니다.
- **수정/삭제**: 상세보기(6번) 화면에서 프롬프트를 수정하거나 삭제할 수 있습니다.
- **즐겨찾기 토글**: 상세보기 화면에서 즐겨찾기를 바로 추가/해제할 수 있습니다.

## 11. Git 작업 내역

**커밋 규칙**
- 기능 하나를 완성할 때마다 커밋을 나누어 진행했습니다. (예: 프롬프트 추가 기능 완성 → 커밋, 검색 기능 완성 → 커밋)
- 커밋 메시지에는 어떤 기능을 추가·수정했는지 알 수 있도록 작성했습니다. (예: `feat: 프롬프트 검색 기능 추가`, `fix: 잘못된 메뉴 입력 시 종료되던 버그 수정`)

**브랜치 전략**
- `main` 브랜치 외에 기능 단위로 별도 브랜치를 만들어 작업했습니다. (예: `feature/list`, `feature/search`)
- 기능 구현이 끝나면 `main` 브랜치로 `checkout` 후 `merge`하여 통합했습니다.
- 새 기능을 추가할 때는 별도 브랜치에서 작업해 `main`에 영향이 없도록 분리했고, 완료된 기능만 `main`에 병합했습니다.

> `git log --oneline --graph` 실행 결과와 브랜치 생성·병합 과정을 보여주는 터미널 캡처를 이 자리에 첨부합니다.
